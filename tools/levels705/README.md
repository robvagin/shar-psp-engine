# TEST75 level.shr: TEST74 + только забор №705 (Глюки, 27.10)

Файлы TEST74 (level.shr собраны 17.10, L1 — 23.10 с COL1 №905) не воспроизводятся полной пересборкой текущим экспортёром: резидент и блобы клеток отличаются (дрейф экспортёра с 17.10). Но секции COL1, PRP, CAR воспроизводятся побайтно при выключателях (L2–L7: SHR_FENCE_ROOF_OLD=1 SHR_FENCE_BRIDGE_OLD=1; L1: SHR_FENCE_ROOF_OLD=1, мост №905 включён) и SHR_FAR_PLAIN=1 SHR_PROP_OWNED_OLD=1. Поэтому уровни TEST75 = файл TEST74 с подменённой секцией COL1 (прецедент TEST54).

1. `lvx.sh ИМЯ N ФЛАГИ…` — экспорт без PVS (3–4 мин); `queue.sh` + `jobs.txt` — очередь по 3.
2. `col1_splice.py BASE DONOR OUT` — COL1 из DONOR в BASE, заголовок @88/@96/@100, REGF.at, смещения блобов += Δ.
3. `colcmp.c`, `diffsegs.c` — всё в COL1 кроме заборов побайтно равно; заборы: что изменилось.
4. mcpr.shr и lmap.shr перепекаются (`tools/mcp_bake.sh`, `tools/lmap_pack.sh`): в них только 4 байта ключа (colhash) отличаются от TEST74, контроль на файле TEST74 воспроизводит его mcpr/lmap.

## №905 мост на L2–L7 (out905)
COL1 = забор №705 + мост №905 (экспорт без выключателей) поверх файлов TEST74. Исключение: на L3 и L6 два куска забора у (−253,87) и (−260,71) возвращены к прежнему верху +1e6 (`segpatch.c`, кусок по середине и нормали). Причина: на дне карты (земля около −44 м, за линией земля ниже, чем с лица) съезд с горки на 22 м/с проезжал конечный верх; с боковыми сдвигами ±0,75 и ±1,5 м без исключения было 11 новых проездов, с исключением 0. Проверка: `bridgechk.c` (LAT=1 — боковые сдвиги): полёт на каждый кусок моста и езда 8/15/22 м/с.

### Возврат верха к TEST74 по приёмке Управления (рой tests/lv75acc, подъезд со стороны лица, 22 м/с)
`segrestore.c NEW OLD X Z NX NZ…`: по точке находится звено TEST74, у всех новых звеньев на его линии y1 := y1 TEST74. Возвращено: L2/L5 старое звено 503 (−70…−103; −386): верх 31,9 вместо +1e6, платформа на 37,4 м, 9 из 51 проезжали на 22 м/с; L3/L6 звено 1026 (R, опущен ROOF-правилом, −5,3 → −2,6; на L6 два звена, 1026 и 1027); L3/L6 вся старая граница (−236,127)–(−271,45) (18 новых звеньев, включая 141/142; до этого исключены 140 и 143). Причина везде одна: съезд/подъезд по линии, где земля за линией ниже, чем с лица (край карты, платформа), конечный верх проезжается; в TEST74 там стена. После возврата со стороны лица: проездов новое = TEST74 на всех L1–L7 (L3 23/23, L6 29/29, остальные 0/0). mcpr/lmap перепечены.
Для сведения: подъезд ОБРАТНО (side=+1, с изнанки) у новых мостовых звеньев проезжает больше, чем TEST74 (бесконечные «границы» держали с обеих сторон); критерий приёмки это не учитывает (с изнанки — вне карты/выше платформы).
